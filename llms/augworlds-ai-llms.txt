# Travel World (Augmented Worlds)

> Agent-native, invite-only travel platform. Members get a personal travel agent that searches and compares real flights and hotels, checks airline flight status by number, pulls city guides, and shapes results with saved loyalty programs and preferences. Checkout is handed to the member as a Stripe Link — nothing is charged without a human present. Exposed to agents as a remote MCP server and an A2A agent card on travel.augworlds.ai. Membership is free but by invitation (private beta).

Generated by API Evangelist on 2026-09-19 from the provider's public pages and discovery documents (method: generated). Travel World publishes no llms.txt of its own (https://augworlds.ai/llms.txt and https://travel.augworlds.ai/llms.txt both 404).

## Agent surfaces

- [MCP server (remote, Streamable HTTP)](https://travel.augworlds.ai/mcp): OAuth 2.1 (dynamic client registration + PKCE S256) or a tvl_ personal access token as Bearer. Anonymous tools/list returns 401 with an RFC 9728 resource_metadata challenge.
- [MCP docs and client setup](https://augworlds.ai/mcp): connection recipes for Claude Code, Claude Desktop / claude.ai Connectors, Cursor and Codex; rate limits (429 + Retry-After); CI token guidance.
- [A2A agent card](https://travel.augworlds.ai/.well-known/agent-card.json): A2A 1.0 card, JSONRPC binding at https://travel.augworlds.ai/a2a, Bearer ApiKey; skills array is empty on the public card (extendedAgentCard: true).
- [OAuth authorization server metadata (RFC 8414)](https://travel.augworlds.ai/.well-known/oauth-authorization-server): scopes mcp:tools:list, mcp:tk:read, mcp:brandlanes:read, mcp:search:read, mcp:profile:apply, mcp:observations:write.
- [OAuth protected resource metadata (RFC 9728)](https://travel.augworlds.ai/.well-known/oauth-protected-resource/mcp)
